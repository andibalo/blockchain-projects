Token URI Format

The token URI should point to a JSON file with this structure: 

{
  "name": "Digital Art Pack Certificate",
  "description": "Purchase certificate for Digital Art Pack",
  "image": "ipfs://QmYourImageHash",
  "attributes": [
    { "trait_type": "Product",  "value": "Digital Art Pack" },
    { "trait_type": "Price",    "value": "0.005 ETH" },
    { "trait_type": "Network",  "value": "Sepolia" }
  ]
}

You can host this JSON on nft.storage or Pinata for free.
