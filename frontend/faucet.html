How the Faucet Works

  • Smart Contract The Faucet is a Solidity contract deployed on Sepolia.
  • Web3 API The website calls requestFunds() via ethers.js — MetaMask signs the transaction.
  • Cooldown A 24-hour cooldown per wallet is enforced on-chain — it cannot be bypassed.
  • Balance The contract must have ETH to send. The owner deposits ETH to refill it.
